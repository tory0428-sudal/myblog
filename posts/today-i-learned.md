# 오늘 배운것

![블로그를 직접 만들며 HTML·CSS·JS를 정리하는 모습](posts/images/today-i-learned/today.jpg)

클로드 코드로 이 블로그를 직접 만들어보면서, HTML·CSS·자바스크립트가 각각 어떤 역할을 하는지 다시 정리해봤다.

## HTML — 구조와 뼈대

- `index.html`, `post.html` 두 페이지로 나눠서 "글 목록"과 "글 상세"의 역할을 분리했다.
- `<meta name="viewport" content="width=device-width, initial-scale=1">`를 넣어야 모바일에서 화면 크기가 제대로 잡힌다.
- `article`, `header` 같은 시맨틱 태그를 쓰면 코드만 봐도 어떤 영역인지 바로 이해된다.

## CSS — 테마와 레이아웃

- CSS 커스텀 프로퍼티(`--bg`, `--fg` 같은 변수)로 색상을 관리하면, 다크모드 전환이 훨씬 쉬워진다. 색상 값을 여기저기 흩어놓지 않고 한 곳에서 바꿀 수 있다.
- `@media (prefers-color-scheme: dark)`로 시스템 설정을 감지하고, `html[data-theme="dark"]` 같은 속성 선택자로 사용자가 수동으로 고른 테마를 덮어쓸 수 있다.
- `@media (max-width: ...)` 미디어 쿼리로 좁은 화면에서 폰트 크기와 여백을 줄여야 가독성이 유지된다.
- `overflow-x: auto`를 코드블록/표에 걸어두면 내용이 길어도 페이지 전체가 가로로 밀리지 않는다.

## 자바스크립트 — 데이터 연결과 동작

- `fetch()`로 `manifest.json`과 마크다운 파일을 읽어와서, 별도 빌드 과정 없이 브라우저에서 바로 렌더링했다.
- 마크다운을 직접 파싱하는 대신 `marked.js` 같은 라이브러리를 한 줄로 불러와 변환을 맡기면 훨씬 간단하다.
- `URLSearchParams`로 `post.html?slug=...`의 쿼리값을 읽어서 어떤 글을 보여줄지 결정했다.
- 다크모드 선택값은 `localStorage`에 저장해야 새로고침 후에도 유지된다.

## 느낀 점

세 가지 언어가 딱 나눠서 일한다: HTML은 "무엇이 있는지", CSS는 "어떻게 보이는지", 자바스크립트는 "어떻게 동작하는지"를 담당한다. 프레임워크 없이 직접 만들어보니 이 역할 구분이 훨씬 명확하게 느껴졌다.
