# 클로드 코드로 2048 미니 게임을 만들어봤다

블로그 한켠에 "미니 웹앱" 코너를 두고, 클로드 코드로 2048 게임을 처음부터 끝까지 만들어봤다. 원래는 홈 화면 미니 웹앱 자리에 바로 올려뒀는데, 그 자리는 앞으로 "프로젝트 사례"들을 위한 공간으로 정리하면서 이 글로 옮겨 기록해둔다.

## 어떻게 만들었나

- **plan**: 게임 규칙(4x4 격자, 방향키로 타일 이동/병합, 2048 도달 시 승리·더 이상 움직일 곳 없으면 패배)과 파일 구조를 `spec.md`로 먼저 정리하고 승인받은 뒤 시작.
- **build**: `game.js`(순수 게임 로직) / `input.js`(키보드·터치 입력) / `main.js`(렌더링, 최고점수 저장)로 역할을 나눠 구현. 외부 라이브러리 없이 순수 HTML/CSS/JS로만 완결.
- **review**: 실제 브라우저에서 방향키 이동, 스와이프, 점수판 갱신, 게임오버/승리 판정, 모바일 반응형(375px), 다크모드까지 항목별로 하나씩 확인. 발견된 문제 없이 통과.

## 기억할 점

- 로직(game.js) / 입력(input.js) / 렌더링(main.js)을 분리해두니, 검증도 항목별로 나눠서 진행하기 훨씬 편했다.
- `localStorage`에 최고점수 하나만 저장해도 게임 하나의 완성도가 확 올라간다.
- 모바일 스와이프는 `touchmove`에서 `preventDefault()`로 스크롤·제스처 충돌만 막아주면, 방향키 이동 로직을 그대로 재사용할 수 있었다.
